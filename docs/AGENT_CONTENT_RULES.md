# 内容生成铁律（给 agent 看的总规则）

> 这份文件给所有生成内容的 agent 看。
> 不管是公众号、V2EX、抖音、小红书、快手、即刻、知乎——都遵守这 7 条铁律。

---

## 铁律 1：分平台调性分流

**同一篇文章要改 4 个版本**——**不是同一篇直接发 4 平台**。

| 平台 | 调性 | AI 协作表达 | 钩子 |
|---|---|---|---|
| **公众号** | 实战 + 陪跑 | 中性 | 场景 + 数字 |
| **抖音** | **教"AI 怎么搭自动化"激进** | "AI 帮我 70%" | 反问 + 数字 + 对比 |
| **V2EX** | 手写派 | **不强调**（淡化）| 求指教姿态 |
| **小红书** | 陪跑温和 | 温和（"我用 AI 帮写"）| 标题党 + emoji |
| **快手** | 同抖音 | 激进 | 直接 + 大白话 |
| **即刻** | 简洁 | 中性 | 短平快 |
| **知乎** | 深度 | 中性 | 长文深度分析 |

---

## 铁律 2：V2EX 反 AI 感

V2EX 是手写派社区——**AI 协作表达会被减分**。

### 严禁
- "AI 帮我 70%"
- "我手写所有代码"（V2EX 知道真相）
- "LLM 只帮我查文档"
- 用 Markdown 标题（`##`、`###`）
- "求关注""求转发"
- "关注公众号""加 V"

### 鼓励
- "Python 手写，没依赖什么框架"
- "filter 逻辑自己写了个价格阈值"
- "接下来想搭 X，求指教"
- "求指点"
- 用纯文本 + 换行
- 字数 300-500 字
- 有 GitHub 链接
- 结尾必有"求指教"

详见 `V2EX_GUIDE.md`。

## 铁律 3：公众号格式铁律

公众号**不能直接复制 Markdown**——**必须用排版工具**。

### 4 个常见坑
1. 字体颜色浅（默认浅灰）
2. 有 `##` 占位符（标题没被解析）
3. 文字大小都一样（H1/H2/H3 没区分）
4. 没有配图（缺图太干）

### 解决方案
1. **秀米编辑器**：自动排版（推荐）
2. **壹伴助手**：浏览器插件一键美化
3. **手动调整**：删占位符、改字号、改颜色

### 配图清单（每篇必加 7 张）
1. 封面图（3:4，900x1200）
2. 开头场景图
3. 痛点对比图
4. 解法架构图
5. 代码截图
6. 结果截图
7. 结尾 CTA 图

详见 `WECHAT_FORMAT_GUIDE.md`。

## 铁律 4：禁止第一人称捏造

### 严禁
- "我用了 XX 工具"（没真用过）
- "我搭了 XX 系统"（只跑通 Steam 推送）
- "XX 天上线"（没真做过）
- "XX 小时搞定"（没真跑过）
- "我儿子问我"（没说过这话）
- "奶爸抱娃刷 XX"（没真做过这个动作）

### 允许
- "我看到""我搜到""我意识到""我准备试"
- "还没用过""等空了试试""我 mark 了"
- "刚跑通 Steam""AI 帮我 70% 写代码"
- "架构我设计""我懂每一行在干嘛"
- "带娃间隙""儿子午睡时""晚上娃睡着后"

---

## 铁律 5：去营销号风格

### 严禁
- "破防了""扎心了""当代酷刑"
- "震惊！""你知道吗？"
- "千万不要""一定要"
- "血亏""亏大了""心痛"
- "彻底改变""颠覆""革命"

### 替换为真实工程师视角
- "今天意识到""才反应过来""突然想通"
- "我算过一笔账：..."
- "结果发现，3 步就搞定了"
- "跑了 3 天，0 错误"
- "能自动化为什么要手动？"

---

## 铁律 6：钩子强化（3 秒抓人）

### 弱钩子（避免）
- "今天刷 X 看到一个工具"
- "我发现了一个好东西"
- "带娃间隙搭了个自动化"

### 强钩子（用这些）
- **反问**："你是否也想一键生成..."
- **数字**："90% 的人不会用 AI 搭自动化"
- **对比**："30 分钟手动 vs 5 分钟自动化"
- **冲突**："我让 AI 写了 70% 代码"
- **身份**："29 岁程序员奶爸，3 天搭通 Steam"

---

## 铁律 7：抖音 30-40 秒紧凑版

```
[0-3s] Hook（反问/数字/对比）
[3-15s] 痛点（讲原来的麻烦）
[15-25s] 实战连接（真实素材）
[25-32s] CTA（评论区扣"教程"）
```

### 关键
- 全程自己说（声音真人感最强）
- 每段不超过 12 秒
- 总字数 ≤ 200 字
- 钩子必须有反问/数字/对比

## agent 输出前自检清单（7 项）

每次输出内容前必查：

- [ ] **平台调性对吗？** —— 4 平台 4 调性
- [ ] **第一人称捏造了吗？** —— "我用了""我搭了"
- [ ] **营销号风格吗？** —— "破防""扎心"
- [ ] **AI 协作表达对吗？** —— 抖音激进/V2EX 淡化/公众号中性
- [ ] **钩子强吗？** —— 反问/数字/对比
- [ ] **数据真实吗？** —— 不编造
- [ ] **格式对吗？** —— V2EX 纯文本 / 公众号配图 / 抖音紧凑
