# V2EX 发帖指南

> V2EX 是手写派技术社区。发对了能拿到技术建议 + 真心读者；发错了会被喷。
> 这份指南教你：怎么发对、怎么不发错。

---

## 一、V2EX 现状（2026）

| 现象 | 应对 |
|---|---|
| 老用户吐槽日常（"没 token""未来何去何从"）| **不跟风**——你的帖是"实战分享"，差异化 |
| 技术深度下降 | **新手姿态反而加分**——"求指教"姿态 |
| 装大神的人变多 | **真诚更稀缺**——你的"辞职带娃 3 年新手"人设反而加分 |
| 直接发 Markdown 不友好 | **用纯文本格式**——不要用 `##` 这种 |

## 二、V2EX 调性铁律

### 必做（10 条）

1. **手写派语气**——"Python 手写，没依赖什么框架"
2. **技术细节**——filter 逻辑、价格阈值、cron 表达式
3. **求指教姿态**——结尾必有"求指点"
4. **真实背景**——"辞职 3 年带娃""跑通 3 天 0 错误"
5. **具体技术栈**——Python + feedparser + cron + PushPlus
6. **开源链接**——GitHub / Gitee
7. **接下来想搭什么**——请教姿态
8. **不卖课**——绝对不要写"关注公众号""加微信"
9. **不夸大**——"跑了 3 天，0 错误"，不写"3 个月"
10. **不用 Markdown 标题**——用纯文本换行

### 必不做（10 条）

1. ❌ "我手写所有代码"（V2EX 知道谁都会用 AI）
2. ❌ "LLM 只帮我查文档"（V2EX 老用户会笑）
3. ❌ "震惊！这个工具太厉害了"（营销号）
4. ❌ "AI 帮我 70%"（V2EX 不强调 AI 协作）
5. ❌ "求关注""求转发"（会被喷）
6. ❌ "关注公众号""加 V"（违规引流）
7. ❌ "教你怎么搭"（装大神）
8. ❌ "30 行代码搞定"（标题党）
9. ❌ "快来试""赶紧用"（销售口吻）
10. ❌ 用 Markdown 标题（`##`、`###`）

## 四、V2EX 正文模板

### 模板 1：新手实战分享（推荐你用这个）

```
29岁，程序员，辞职三年在家带娃。儿子一岁多，最近趁他午睡，刚跑通一个 Steam 好价推送自动化，跑了 3 天 0 错误。

背景：平时刷 Steam 看打折，但手动刷太费时间，想搞个自动推送。技术选型上，用 feedparser 解析 Steam 的 RSS 好价源，requests 拉数据，cron 定时 6 小时跑一次，PushPlus 推送到微信。Python 手写，没依赖什么框架，核心就三块：解析、过滤、推送。filter 逻辑自己写了个价格阈值，低于 50% off 才推，避免噪音。

跑了 3 天，cron 日志里 0 错误，稳定得有点意外。GitHub 已开源：fcqcc/yqZan。

接下来想搭 GitHub Trending 推送，每天自动抓 trending 仓库，推个摘要到微信。目前想法是用 GitHub API 抓 trending 数据，但 trending 没有官方 API，考虑用第三方 scraping 或 RSS Bridge。求指教，有没有更稳的方案？比如用 GitHub 的 explore 接口？或者有现成 RSS 源能直接喂给 feedparser？

手写派社区，求指点。
```

### 模板 2：求优化建议

```
搭了个 Steam 好价推送，跑通了，3 天 0 错误。但有些地方想优化，求建议：

1. cron 6 小时一次够不够？要不要改 1 小时？
2. RSS 源只有 Steam 官方，能不能加上其他平台的？
3. PushPlus 免费版有额度限制吗？
4. 代码只有 30 行，但全是 if-else，有没有更 Pythonic 的写法？

技术栈：Python 3.12 + feedparser + requests + cron + PushPlus
阿里云 2 核 4G。

代码：https://github.com/fcqcc/yqZan

求指点。
```

### 模板 3：踩坑日记

```
搭 Steam 推送踩了几个坑，记录一下：

坑 1：feedparser 解析中文 RSS 乱码
解决：url 加 ?l=schinese 参数

坑 2：cron 不执行
解决：crontab -e 加 PATH=/usr/local/bin:/usr/bin:/bin

坑 3：PushPlus token 报错 403
解决：检查环境变量是否 source

代码 30 行，跑了 3 天 0 错误。开源在 fcqcc/yqZan。

新手求指教，有没有更优雅的写法？
```

## 八、核心心法

> **V2EX = 技术分享社区，不是涨粉引擎**
> **新手姿态 > 装大神**
> **Python 手写 > AI 协作 70%**
> **求指教 > 教你**
> **GitHub 链接 > 公众号引流**

**预期**：发完 V2EX 可能没评论、可能没点赞——**这是正常的**。
**收获**：1-2 个真心交流的技术朋友 = 比 100 个抖音点赞更值钱。
