# 公众号排版指南

> 公众号不能直接复制 Markdown——会出 4 个问题。
> 这份指南教你：怎么避免 + 怎么排版好看。

---

## 一、Markdown 转公众号的 4 个坑

### 坑 1：字体颜色浅

**原因**：
- Markdown 转纯文本时，主题色丢失
- 默认浅灰色（不适合公众号深色背景）

**解决**：
- 用排版工具（秀米/135/壹伴）转换
- 或手动选中 → 改字体颜色为 `#333333`

### 坑 2：有 `##` 占位符

**原因**：
- 公众号编辑器不识别 Markdown 标题
- `## 标题` 直接显示成"## 标题"

**解决**：
- 用排版工具（自动转换）
- 或手动替换：`## ` → 二级标题样式（18px 粗体）

### 坑 3：文字大小都一样

**原因**：
- Markdown 转纯文本时，H1/H2/H3 没区分
- 全是默认字号（15px）

**解决**：
- 用排版工具（自动分级）
- 或手动调：
  - H1 标题：24px 粗体
  - H2 标题：20px 粗体
  - H3 标题：18px 粗体
  - 正文：16px 常规
  - 引用：14px 灰色

### 坑 4：没有配图

**原因**：
- 纯文字内容太干
- 公众号用户爱"图 + 文"

**解决**：
- **每段配 1 张图**（架构图 / 流程图 / 截图）
- **封面图必加**（3:4 比例，900x1200）
- **结尾 CTA 图**（公众号二维码）

## 二、3 套排版解决方案

### 方案 A：秀米编辑器（推荐）

**网址**：https://xiumi.us/

**操作**：
1. 注册登录秀米
2. 新建图文 → 选模板（找"科技风""IT 男"等）
3. 复制 Markdown 内容到秀米
4. 秀米自动转换 + 美化
5. 一键复制到公众号编辑器

**优点**：
- 模板多（300+）
- 自动排版
- 字体颜色自动配

**缺点**：
- 免费版有功能限制
- 部分模板要 VIP

### 方案 B：壹伴助手

**网址**：https://yiban.io/

**操作**：
1. 浏览器装壹伴插件
2. 打开公众号后台编辑器
3. 壹伴自动加载排版工具
4. 一键"AI 排版"或"一键美化"

**优点**：
- 公众号原生编辑器
- 一键排版
- 配图库大

**缺点**：
- 要装浏览器插件
- 部分高级功能要付费

### 方案 C：手动排版

**操作**：
1. 复制 Markdown 内容到公众号编辑器
2. 手动调整：
   - 删掉 `## ` `### ` 占位符
   - 选中标题 → 改样式（字号 + 粗体）
   - 改字体颜色为 `#333333`
   - 改行间距为 1.75
   - 改段间距为 12px
3. 手动插图（封面 + 段落图 + 结尾图）

**优点**：
- 0 成本
- 完全可控

**缺点**：
- 慢（10-15 分钟/篇）
- 容易漏改

## 三、配图清单（每篇文章必加）

| 位置 | 配图 | 尺寸 |
|---|---|---|
| **封面** | 3:4 封面图 | 900x1200 |
| **开头** | 场景图（带娃/书桌/电脑）| 900x500 |
| **痛点** | 对比图（手动 vs 自动）| 900x600 |
| **解法** | 架构图 / 流程图 | 900x800 |
| **代码** | 代码截图（带高亮）| 900x500 |
| **结果** | 截图（推送成功）| 900x500 |
| **结尾 CTA** | 公众号二维码 | 900x900 |

**总共 7 张图** = **专业公众号文章标准**。

## 四、配图制作工具

### 工具 1：Canva（最推荐）

**网址**：https://www.canva.com/

**用途**：
- 封面图（3:4 模板）
- 流程图 / 架构图
- 二维码装饰
- 段落分隔图

**优点**：
- 模板多
- 拖拽式
- 免费版够用

### 工具 2：Pillow（Python）

**用途**：
- 9 张图卡片
- 标题图
- 段落分隔图

**优点**：
- 自动化
- 中文友好（之前用过）

### 工具 3：豆包生图（之前讨论过）

**用途**：
- 场景图（程序员、书桌、奶爸等）
- 风格统一用"3D 皮克斯"

**注意**：
- 不用豆包加长文字（用 Canva 加）

## 五、公众号标准排版模板

### 标题区

```
大标题：22-24px 粗体，居中
副标题：14-16px 灰色，居中
作者：12px 灰色，右对齐
```

### 正文区

```
段落间距：12px
行间距：1.75-2.0
字体颜色：#333333
字号：15-16px
两端对齐
```

### 强调区

```
引用：14px 灰色 #888888，左边 4px 蓝色边框
加粗：16px 粗体
高亮：黄色背景 #FFF8DC
链接：蓝色 #576B95
```

### 代码区

```
背景色：#F7F7F7
边框：1px solid #E0E0E0
圆角：6px
内边距：12px
字体：Consolas / Monaco
字号：13px
```

### 图片区

```
居中
上下间距：20px
图说：13px 灰色，居中
```

```yaml

  style: 实战派 + 陪跑感
  ai_collaboration: 中性
  main_line: 工具+案例+思考+智能体教程入口

    - 封面：3:4（900x1200）

    - 开头场景（100 字内）

    - 输出 Markdown 标题
    - 不给配图清单
    - 不给排版建议
    - 复制代码时用 ``` 而不是缩进
```
