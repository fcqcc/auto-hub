## 三、抖音核心教训（最重要）

### 数据真相

| 指标 | 数据 | 优秀值 | 差距 |
|---|---|---|---|
| 2s 跳出率 | 39.34% | <20% | 差 50% |
| 完播率 | 9.8% | 15%+ | 差 35% |
| 平均播放时长 | 5s | 15s+ | 差 67% |

**根本原因**：**前 2 秒钩子没抓住人**。

### 错误钩子案例

| ❌ 错误钩子 | 评价 |
|---|---|
| "你是否也想一键生成这样的文章" | 太温和、不抓人 |
| "还在天天刷 GitHub？别傻了" | 说教、居高临下 |
| "AI 时代，让工具替你打工" | 营销号、空洞 |
| "每天手动刷 GitHub 半小时" | 没有对比、没有钩子 |

### 正确钩子公式

```
反问开头 + 揭密视角 + 教学承诺 + 数字具体 + 强名词
```

### 老板给的标杆钩子

```
"你是否看到过这样的视频（AI 神器项目一个月狂揽多少 star），
这种视频的数据是怎么来的？"
```

**为什么强**：
- ✅ 反问开头（"你是否看到过"）
- ✅ 揭密视角（"数据是怎么来的"）
- ✅ 强名词（"AI 神器""star"）
- ✅ 数字具体（"一个月""多少 star"）
- ✅ 覆盖 100% 抖音用户（都看过 AI 神器视频）

### agent 写抖音脚本铁律

```yaml
douyin_hook_rules:
  必须包含:
    - 反问开头（"你是否..."）
    - 揭密 / 痛点 / 数字 之一
    - 具体名词（不是泛指）
    - 数字具体（X 分钟 / X 天 / X%）
  
  严禁:
    - 说教语气（"别傻了""你应该"）
    - 营销号句式（"AI 时代""让 X 替你打工"）
    - 温和开头（"今天""我发现"）
    - 泛指名词（"工具""系统"）
  
  检查清单:
    - 0-3 秒是否有数字？✅/❌
    - 是否有强名词（AI / GitHub / Steam）？✅/❌
    - 是否有反问 / 对比 / 冲突？✅/❌
    - 是否覆盖抖音大众用户？✅/❌
```

## 四、快手核心教训：标题指令 52 分

### 数据真相

**快手标题指令评估 = 52 分**（标题与视频内容一致性欠佳）

**老板标题**：`AI 替我搭的游戏折扣平台折后 20 全要`

**问题**：
- 标题承诺"折后 20 全要"——视频没具体演示
- 标题承诺"AI 替我搭"——视频不是核心
- 标题与内容关联度低

### agent 写快手/抖音标题铁律

```yaml
title_rules:
  公式: 数字 + 数字 + 反差 / 冲突 / 解决方案
  
  必须:
    - 标题承诺 = 视频内容 100% 兑现
    - 数字具体（X 行 / X 分钟 / X%）
    - 强名词（AI / GitHub / Steam）
  
  检查清单:
    - 视频里有承诺的"30 行代码"吗？✅/❌
    - 视频里有承诺的"5 分钟跑通"吗？✅/❌
    - 视频里有承诺的"折后 20 全推"吗？✅/❌
```

### 优化后的快手标题

```
❌ "AI 替我搭的游戏折扣平台折后 20 全要"
✅ "AI 帮我 30 行搭游戏折扣平台 5 分钟跑通"
```

**改进**：
- "AI 帮我"——明确 AI 协作
- "30 行"——具体数字（视频里有）
- "5 分钟跑通"——具体数字（视频里有）

3. **营销号风格**："别急""视觉舒适""效率拉满"
4. **缺智能体教程入口**
5. **缺配图清单**

### agent 写公众号铁律

```yaml
wechat_rules:

    - 钩子结尾："关注『游戏好价精选』，每周 1 套新自动化"
  
  排版:
    - 不用 Markdown 标题（## / ###）
    - 用秀米 / 壹伴 / 手动排版
    - 字号分级（H2 18px，正文 16px）
```

## 六、V2EX 核心教训：单纯技术分享跑不通

### V2EX 老用户真正关心什么

| ❌ agent 以为 | ✅ 实际关心 |
|---|---|
| 技术细节（GitHub API + sqlite3 + cron）| **怎么用技术变现** |
| 代码怎么写（filter 逻辑、对比阈值）| **怎么接私活 / 副业** |
| 我搭了什么（星标监控、自动化平台）| **怎么从程序员变成产品人** |
| AI 帮我写 70%（技术细节）| **AI 时代怎么不被淘汰** |
| 跑了 3 天 0 错误（成果展示）| **35 岁焦虑 + 带娃 + 工作 + 副业怎么平衡** |

### V2EX 4 个评论揭示的真相

```
1. "OP 是兴趣还是指望这个吃饭？" → 变现焦虑
2. "家里有矿吧" → 家庭焦虑
3. "不如健身" → 健康焦虑
4. "遛狗找富婆" → 躺平焦虑
```

**V2EX 老用户不缺技术——他们缺"技术 → 钱"的路径**。

### agent 写 V2EX 帖铁律

```yaml
v2ex_post_rules:
  严禁:
    - 单纯技术展示（他们都会写代码）
    - "我搭了什么"开头（不是他们关心的）
    - AI 协作技术细节（淡化处理）
  
  必加:
    - 真实数据（公众号涨 X%、抖音涨 X%、月收入 0）
    - AI 时代经验分享（不是技术细节）
    - 求指教"变现"（不是技术细节）
    - 求指教"AI 时代竞争力"
    - 求指教"带娃 + 工作 + 副业怎么平衡"
  
  求指教样本:
    - "程序员副业怎么变现？"
    - "公众号 800 粉能接广告吗？"
    - "AI 时代程序员核心竞争力是什么？"
    - "你们怎么平衡带娃 + 工作 + 副业？"
  
  节点:
    - 主节点: programmer
    - 副节点: steam
  
  格式:
    - 纯文本，不用 Markdown 标题
    - 字数 300-500 字
    - 有 GitHub 链接
    - 结尾有"求指教"
```

## 九、核心心法

> **抖音钩子 = 反问 + 揭密 + 数字 + 强名词**——**覆盖 100% 用户**
>
> **V2EX 老用户 = 不缺技术，缺变现**——**求指教"钱"**
>
> **公众号不能违规引流**——**直接说 GitHub 链接，不写"回复关键词"**
>
> **agent 写之前先复述意图**——**避免跑偏**

**3 个平台各有调性**：
- 抖音：揭密 + 反问
- V2EX：变现求指教
- 公众号：实战 + 智能体教程
